# ZRIGID (rigid packing pricing) - read-only in the Costing Cockpit (EDS, client 900, transport EDSK9B0EPN)

Transaction ZRIGID = program `ZMM_MOLD_INFO_RECORD` ("Rigid Pricing Simulation"): the bottom-up rate (per 1000 pieces) of a rigid plastic packing item per mould and vendor, then (not here) the info record.

**Objects**
- `ZRIGID_S_ROW` (structure, generated by `gen_rigid.py`), `ZCL_MM_RIGID_COST` (this folder), MPC_EXT method `rigid_define` (`mpc_rigid_define.abap`), DPC_EXT branch `RigidSet` (`dpc_rigid_branch.abap`, placed before `ls_par = wac_par(` in `get_entityset`, and `RigidSet` added to the "other sets" exclusion).
- Entity set `RigidSet`, filters `Matnr`, `Werks`, `Gjahr`, `Mode`: `C` (default) calc, `F` flag, `B` budget, `H` history, `U` usage of a polymer.

**Read-only by design:** no `ME_INFORECORD_MAINTAIN`, no write to `ZMM_RIGID_COST`, no COMMIT. Plant authorisation: `ZCL_MM_BOM_COST_AUTH=>check_plant`.

**Rows (Grain):** F item has moulds (A819) / M mould x vendor build-up (ZMRT, ZPBR, ZMBX, ZPPB, ZMFG, ZITC, ZMAR ... same formulas as the program) / B BOM component of an M row /
D budget (ZCOMPONENT; `BomQty` carries the price unit) / P packing budget build-up (ZPKG_BUD_ITEM, latest scenario) / H rates saved by earlier ZRIGID runs (ZMM_RIGID_COST) / U rigid items using a polymer.

**Differences from the program:** all vendors of a mould are returned (the program takes the first vendor only); several moulds per item are returned; the plant is a filter (the program: one plant).
`TotOutMon` keeps the program's `output x 24`.

**Tested on EDS** with a temporary class (deleted): item 151000753 / plant UN13 -> 3 moulds, vendor 99, landed 1816 / 1703 / 1741 per 1000 (the program saved 1908 .. 2035 in 2022 with other conditions); item 151002533 -> NOBOM message; polymer 151002525 -> usage row.
**Not verified:** the gateway metadata of `RigidSet` (refresh and call `RigidSet?$filter=Matnr eq '151000753' and Werks eq 'UN13' and Mode eq 'F'`), ZCOMPONENT / ZPKG_BUD_ITEM rows (empty on EDS for these items), A363 box/margin conditions (none on EDS).
